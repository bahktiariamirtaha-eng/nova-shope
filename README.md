# 🛒 NOVA DIGITAL

یک فروشگاه آنلاین مدرن برای نمایش و مدیریت محصولات دیجیتال، طراحی‌شده با **HTML، CSS و JavaScript**.

## ✨ امکانات

* 🛍️ نمایش محصولات در دسته‌بندی‌های مختلف
* 💻 دسته‌بندی لپ‌تاپ، موبایل، مانیتور و لوازم جانبی
* 🔍 نمایش اطلاعات محصول در Modal
* 🛒 افزودن محصول به سبد خرید
* ❤️ سیستم علاقه‌مندی‌ها
* 💾 ذخیره اطلاعات سبد خرید و علاقه‌مندی‌ها با `localStorage`
* 📱 طراحی کاملاً Responsive
* 🎞️ اسلایدر محصولات با Swiper
* 📂 دکمه «نمایش بیشتر» برای محصولات
* 🎨 طراحی مدرن با افکت‌های Hover و Glassmorphism
* ⚡ تعاملات صفحه با JavaScript

## 🛠️ تکنولوژی‌ها

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Swiper.js
* LocalStorage

## 🛒 بخش فروشگاه

صفحه Shop شامل محصولات دسته‌بندی‌شده است و کاربر می‌تواند:

1. محصولات را مشاهده کند.
2. اطلاعات محصول را در Modal ببیند.
3. محصول را به سبد خرید اضافه کند.
4. محصول را به علاقه‌مندی‌ها اضافه یا حذف کند.
5. محصولات بیشتری را با دکمه «نمایش بیشتر» مشاهده کند.

## 💾 ذخیره اطلاعات

اطلاعات سبد خرید و علاقه‌مندی‌ها در مرورگر کاربر و با استفاده از `localStorage` ذخیره می‌شوند.

```js
localStorage.setItem("novaCart", JSON.stringify(cart));
```
